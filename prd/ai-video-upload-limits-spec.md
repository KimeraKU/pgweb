# AI Video 上传参数限制规格

> 文档版本：V1.2
> 更新日期：2026-08-13
> 适用页面：`/ai-video`

## 1. 限制规则

- 全能参考的素材类型、数量、大小、格式、尺寸、时长及组合限制，全部以当前模型接口返回结果为准，前端不得写死统一限制。
- 首尾帧固定为一张首帧和至多一张尾帧，且只能上传图片；图片本身的大小、格式和尺寸限制仍以模型接口返回结果为准。
- 接口未返回的限制不在前端展示或推测，由服务端在创建任务时完成最终校验；模型能力整体加载失败时禁用上传和生成。
- 选择文件及切换模型或模式后均需重新校验。因切换而不兼容的历史素材暂存隐藏且不进入生成请求；当前模型下新上传并校验失败的素材显示具体原因，并在删除或替换前阻塞生成。
- 已知限制必须提示具体原因，文案中同时包含实际值与允许值，不得统一显示“请检查素材是否符合要求”。

## 2. 接口限制参数

接口至少需要表达下列能力，实际字段名可沿用现有协议：

| 限制类型 | 接口参数 | 用途 |
| --- | --- | --- |
| 素材类型 | `supported_media_types` | 当前模型支持图片、视频、音频中的哪些类型 |
| 总数量 | `max_total_count` | 全能参考允许上传的素材总数 |
| 分类数量 | `max_count_by_type` | 图片、视频、音频各自允许上传的数量 |
| 单文件大小 | `max_file_size_by_type` | 各类素材单个文件的最大体积 |
| 总文件大小 | `max_total_size` | 一次生成允许提交的素材总体积；接口未返回时不校验 |
| 文件格式 | `allowed_formats_by_type` | 各类素材允许的扩展名或 MIME 类型 |
| 图片尺寸 | `min_width`、`max_width`、`min_height`、`max_height` | 图片及视频画面的最小、最大宽高 |
| 宽高比 | `allowed_aspect_ratios` 或 `aspect_ratio_range` | 允许的固定宽高比或宽高比范围 |
| 媒体时长 | `min_duration`、`max_duration` | 视频、音频允许的最短和最长时长 |
| 素材组合 | `combination_rules` | 图片、视频、音频是否允许混合及允许的组合方式 |

大小统一由接口返回字节数，页面转换为易读单位；尺寸显示为“宽 × 高 px”；时长统一显示为秒或“分:秒”。限制说明和错误文案必须使用同一份接口数据。

## 3. 校验文案

下列 `{变量}` 均需替换为当前文件的实际信息和模型接口返回值，不得将占位符直接展示给用户。

| 校验场景 | 提示文案 |
| --- | --- |
| 素材类型不支持 | 当前模型不支持上传{素材类型}，请选择{支持的素材类型} |
| 素材总数超限 | 最多可上传{最大总数}个参考素材，当前已选择{当前数量}个 |
| 单类素材数量超限 | 最多可上传{最大数量}个{素材类型}，当前已选择{当前数量}个 |
| 单文件过大 | {文件名}大小为{实际大小}，不能超过{最大大小} |
| 素材总体积超限 | 素材总大小为{实际总大小}，不能超过{最大总大小} |
| 文件格式不支持 | {文件名}为{实际格式}格式，仅支持{支持格式} |
| 文件类型无法识别 | 无法识别{文件名}的文件类型，请重新导出后上传 |
| 尺寸过小 | {文件名}尺寸为{实际宽度} × {实际高度}px，最小尺寸为{最小宽度} × {最小高度}px |
| 尺寸过大 | {文件名}尺寸为{实际宽度} × {实际高度}px，最大尺寸为{最大宽度} × {最大高度}px |
| 宽高比不支持 | {文件名}宽高比为{实际宽高比}，仅支持{允许宽高比} |
| 时长过短 | 当前模型支持的最短时长为{最短时长}，{文件名}时长为{实际时长} |
| 时长过长 | 当前模型支持的最长时长为{最长时长}，{文件名}时长为{实际时长} |
| 素材组合不支持 | 当前模型仅支持{允许组合}，不支持{当前组合} |
| 首尾帧上传了非图片 | 当前模式下首帧和尾帧仅支持图片，{文件名}为{实际素材类型}，请重新选择 |
| 缺少首帧 | 当前模式必须上传首帧图片，请先上传 |
| 文件损坏或无法读取 | 无法读取{文件名}，请检查文件是否损坏后重新上传 |
| 模型能力加载失败 | 暂时无法获取当前模型的上传要求，请稍后重试 |
| 非限制类上传失败 | {文件名}上传失败，请重试 |

已知数量、大小、格式、尺寸、宽高比、时长或组合问题必须使用对应具体文案；“{文件名}上传失败，请重试”仅用于网络异常、上传服务异常等无法归因于参数限制的场景。

## 4. 页面展示与验收

- 上传入口附近展示当前模型的格式、数量、大小、尺寸和时长限制；接口未返回的项目不展示。
- 单文件问题显示在对应素材附近；总数量、总体积和组合问题显示在上传区附近。
- 同一文件存在多个问题时，可合并展示全部原因；至少必须展示用户当前需要处理的第一条具体原因。
- 当前上传区存在校验失败的新素材、素材仍在上传或模型能力加载失败时，生成按钮禁用；因切换而暂存隐藏的历史素材不阻塞生成。
- 切换模型或模式后，限制说明同步更新；不兼容历史素材不在上传框中展示，也不计入数量和组合限制。
- 暂存素材未被对应素材位的新上传替换时，切回兼容模型或模式后自动恢复；首尾帧按首帧位、尾帧位对应，全能参考按原上传顺序优先填补隐藏位置；用户主动删除的素材不得恢复。
- 全能参考和首尾帧均复用本规格中的文件校验与错误文案，前端和服务端保持一致。
