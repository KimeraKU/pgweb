## 1. 产品概述

### 1.1 产品定位

Aggregation Editor 是一个基于 Web 的在线图片编辑器，提供图层管理、多类型内容编辑、布局模板等功能，旨在为用户提供简单易用的图片创作工具。

### 1.2 核心价值

- **图层化管理**：支持多图层编辑，灵活控制每个元素的显示、锁定和层级
- **多类型内容**：支持文本、图片、布局、形状、背景等多种内容类型
- **模板化设计**：提供丰富的布局模板和设计元素，快速创建专业作品
- **实时预览**：所见即所得的编辑体验
- **多语言支持**：支持中英文切换，满足国际化需求

### 1.3 目标用户

- 内容创作者
- 社交媒体运营人员
- 设计师（初级到中级）
- 个人用户

## 3. 用户界面设计

### 3.1 编辑器头部 (Editor Header)

**位置**：页面顶部，固定显示

**功能按钮**：
- **Logo**：品牌标识
- **Create New**：创建新项目
- **Undo/Redo**：撤销/重做操作
- **Language**：语言切换（中文/英文）
- **Download**：下载当前作品
- **Pro**：升级到专业版（非 Pro 用户显示）

### 3.2 左侧边栏 (Left Sidebar)

**位置**：页面左侧，宽度 80px

**标签页列表**（从上到下）：
1. **Apps** - AI 应用集合
2. **Ratio** - 画布尺寸设置
3. **Templates** - 设计模板
4. **Layout** - 布局模板（独立于 Templates）
5. **Upload** - 文件上传
6. **Text** - 文字工具
7. **Image** - 图片工具
8. **Assets** - 资源库（形状、贴纸）
9. **Background** - 背景设置

**交互**：
- 点击标签切换对应内容面板
- 当前激活标签高亮显示（青色背景）
- 特殊模式（如布局选择模式）会高亮对应标签（黄色背景，脉冲动画）

### 3.3 内容面板 (Tab Content)

**位置**：左侧边栏右侧，宽度 320px

**功能**：根据左侧边栏选中的标签显示对应内容

#### 3.3.1 Ratio 标签页

**功能**：
- **自定义尺寸**：宽度/高度输入框，单位选择（px），锁定比例按钮，裁剪按钮
- **搜索框**：搜索预设尺寸
- **社交媒体尺寸**：Instagram Story、YouTube Thumbnail、Facebook Profile 等
- **打印尺寸**：Banner、A4、A3 等

#### 3.3.2 Layout 标签页

**功能**：
- **图片数量选择**：1-14 张图片的布局模板
- **布局模板展示**：网格展示不同布局方案
- **布局选择模式**：点击布局工具后，进入特殊选择模式，显示提示横幅

#### 3.3.3 Templates 标签页

**说明**：不含布局模板，布局已独立至 Layout 标签页。

**功能**：
- **搜索框**：搜索设计模板
- **推荐工具**：AI Design、Trending、Seasonal 三个快速入口
- **模板分类**：
  - **商业营销 (Marketing)**：商业推广、营销活动相关模板
  - **社交媒体 (Social)**：社交媒体发布、分享相关模板
  - **个人效率 (Utility)**：个人事务、效率工具相关模板
  - **视觉艺术 (Art)**：艺术创作、视觉设计相关模板
  - **AI Filter**：AI 滤镜效果模板
  - **AI Video**：AI 视频相关模板
  - **生命瞬间 (Moments)**：生活记录、重要时刻相关模板
  - **全球节日 (Festivals)**：节日庆典、文化活动相关模板
- **模板展示**：每个分类以 3 列网格展示模板卡片
- **模板信息**：显示模板名称、颜色预览、徽章标识（如 PLUS 标识）
- **查看更多**：每个分类提供 "See more" 按钮（待实现功能）

#### 3.3.4 Text 标签页

**功能**：
- **添加文字按钮**
- **推荐工具**：AI Text、Text Effects、Templates
- **文字模板**：预设文字样式
- **文字样式**：Heading、Subheading、Body、Caption、Quote、List

#### 3.3.5 Image 标签页

**功能**：
- **搜索框**：搜索图片
- **我的图片**：用户上传的图片，支持上传
- **推荐工具**：AI Generate、Remove BG、Enhance
- **素材图片**：图库展示

#### 3.3.6 Assets 标签页

**功能**：提供资源库，包括形状和贴纸

**内容结构**：
1. **搜索栏**：顶部固定搜索框
2. **Elements Section**：几何形状元素（星形、心形、圆形、方形、三角形、六边形）
   - 点击形状添加到画布，创建 **Shape 类型图层**
3. **Stickers Section**：贴纸分类
   - Birthday Shoutouts
   - Birthday photo album
   - All happy birthday
   - It's My Birthday
   - 每个分类下有多个贴纸（emoji 形式）
   - 每个分类支持二级标签筛选（横向滚动）
   - 标签包括：All, Cake, Party, Celebration, Gift, Balloons, Wishes, Greeting 等
   - 点击贴纸添加到画布，创建 **Image 类型图层**（贴纸作为图片处理）

**交互**：
- 点击形状可添加到画布（创建 Shape 图层）
- 点击贴纸可添加到画布（创建 Image 图层）
- 贴纸分类支持二级标签筛选
- 标签支持横向滚动，带左右箭头控制

**图层类型说明**：
- **Shape 图层**：用于几何形状元素（Star, Heart, Circle, Square, Triangle, Hexagon）
- **Image 图层**：用于图片和贴纸（sticker 作为图片类型处理）
- 不再使用单独的 Asset 图层类型，已拆解为 Shape 和 Image 两种类型

#### 3.3.7 Background 标签页

**功能**：
- **分类选择**：All、New、Popular、Minimal、Abstract、Patterns、Gradients
- **自定义背景**：上传背景图片
- **颜色选择**：预设色块和拾色器
- **背景模板**：预设背景样式

#### 3.3.8 Upload 标签页

**功能**：
- **分类标签**：All、Images、Fonts
- **文件列表**：显示已上传的文件（图片/字体）
- **上传按钮**：底部固定，支持图片和字体上传
- **文件操作**：图片可添加到画布、删除

#### 3.3.9 Apps 标签页

**功能**：
- **搜索框**：搜索 AI 应用
- **应用网格**：3列网格展示各种 AI 工具
- **应用信息**：名称、图标、徽章（PLUS、NEW 等）

### 3.4 画布区域 (Editor Canvas)

**位置**：页面中央，自适应容器大小

**功能**：
- **画布显示**：根据设置尺寸显示画布，保持宽高比；默认画布尺寸 972×972，显示区域按容器约 88% 缩放以预留上方工具栏空间；图层工具栏在任意缩放比例下保持固定视觉大小
- **图层渲染**：按 zIndex 顺序渲染所有图层
- **图层选择**：点击图层选中，点击空白区域取消选择或选中背景
- **图层拖拽**：选中图层可拖拽移动位置
- **图层缩放**：选中图层显示缩放控制点，可调整大小
- **背景图层**：特殊图层，始终存在，点击画布空白区域选中
- **锁定图层**：锁定后显示黄色边框和"Locked"提示，不可编辑
- **缩放控制**：支持画布缩放（放大/缩小/全屏/手型工具）

**图层类型**：
- **Layout 图层**：多框架布局，每个框架可单独添加图片
- **Text 图层**：文字内容，支持样式设置
- **Image 图层**：图片内容（包括贴纸）
- **Shape 图层**：几何形状元素（星形、心形、圆形、方形、三角形、六边形等）
- **Background 图层**：背景（颜色、图片、渐变）

**图层类型优化说明**：
- 原 **Asset 图层**已拆解为 **Shape 图层**和 **Image 图层**
- **Shape 图层**：用于几何形状元素，从 Assets 标签页的 Elements 部分添加
- **Image 图层**：用于图片和贴纸，从 Assets 标签页的 Stickers 部分添加的贴纸也会创建 Image 图层

### 3.5 右侧边栏 (Right Sidebar)

## 4. 功能详细说明

### 4.1 图层管理系统

#### 4.1.1 图层属性

每个图层包含以下属性：
- `id`: 唯一标识符
- `name`: 图层名称
- `type`: 图层类型（text/image/layout/shape/background）
- `visible`: 是否可见（默认 true）
- `locked`: 是否锁定（默认 false）
- `zIndex`: 层级索引（数值越大越在上层）
- `x, y`: 位置坐标（百分比）
- `width, height`: 尺寸（百分比）
- 类型特定属性（如 text 的 text、fontSize 等）

#### 4.1.2 图层操作

**选择图层**：
- 点击画布上的图层元素选中
- 点击右侧边栏图层列表选中
- 点击画布空白区域选中背景图层
- 点击画布外部灰色区域取消选择

**移动图层**：
- 选中图层后，拖拽图层主体移动位置
- 锁定图层不可移动

**调整图层大小**：
- 选中图层后，拖拽四角或边缘的控制点调整大小
- 锁定图层不可调整

**图层排序**：
- 在右侧边栏通过拖拽手柄上下拖动改变顺序
- 背景图层不可拖拽
- 排序后自动更新 zIndex

**删除 Layout 图层**：删除布局图层时同步清除当前选中的布局引用（selectedLayout），避免画布继续显示已删除的布局占位

**图层可见性**：
- 点击眼睛图标切换显示/隐藏
- 隐藏的图层不在画布上显示

**图层锁定**：
- 点击锁定图标切换锁定状态
- 锁定的图层显示黄色边框和"Locked"提示
- 锁定的图层不可移动、缩放，不显示工具栏

### 4.2 布局选择模式

**触发方式**：选中布局图层后，点击工具栏的"Layout"工具

**模式特点**：
- 页面显示灰色蒙层（覆盖除左侧边栏外的所有区域）
- 左侧边栏的 Layout 标签高亮显示（黄色背景，脉冲动画）
- Layout 标签页顶部显示提示横幅："请选择一个布局模板来替换当前布局"
- 点击蒙层或选择新布局后退出模式

### 4.3 画布尺寸管理

**自定义尺寸**：
- 输入宽度和高度（单位：px）
- 锁定按钮保持宽高比
- 裁剪按钮（待实现功能）

**预设尺寸**：
- 社交媒体尺寸：Instagram Story (1080x1920)、YouTube Thumbnail (1280x720) 等
- 打印尺寸：A4 (2480x3508)、A3 (3508x4961) 等

### 4.4 文件上传

**支持格式**：
- 图片：image/*
- 视频：video/*

**功能**：
- 单文件或多文件上传
- 文件预览
- 添加到画布
- 删除文件

### 4.5 多语言支持

**支持语言**：
- 中文（zh）
- 英文（en）

**切换方式**：
- 编辑器头部右上角语言切换按钮
- 点击切换语言，界面文案实时更新

**翻译范围**：
- 所有界面文案
- 按钮标签
- 工具提示
- 错误信息

## 5. 技术实现要求

### 5.1 技术栈

- **框架**：Next.js 14/15 (React 18/19)
- **语言**：TypeScript
- **样式**：Tailwind CSS
- **图标**：Lucide React
- **状态管理**：React Hooks (useState, useContext)

### 5.2 组件架构

```
src/
├── app/
│   └── editor/
│       └── page.tsx              # 编辑器主页面
├── components/
│   └── editor/
│       ├── editor-header.tsx    # 编辑器头部
│       ├── editor-canvas.tsx    # 画布组件
│       ├── editor-toolbar.tsx   # 编辑器工具栏
│       ├── layer-toolbar.tsx    # 图层工具栏
│       ├── left-sidebar.tsx     # 左侧边栏
│       ├── right-sidebar.tsx    # 右侧边栏
│       └── tab-content.tsx      # 内容面板
├── contexts/
│   └── language-context.tsx     # 语言上下文
└── lib/
    └── i18n.ts                  # 国际化翻译
```

### 5.3 关键实现点

**图层渲染**：
- 使用绝对定位（absolute）布局图层
- 按 zIndex 升序排序渲染（确保层级正确）
- 使用百分比定位和尺寸，适配不同画布大小

**拖拽排序**：
- 使用鼠标事件（mousedown、mousemove、mouseup）实现
- 通过图层 ID 而非索引进行排序，避免索引错乱
- 实时更新 zIndex 并同步到画布渲染

**图层工具栏**：
- 根据图层类型动态生成工具列表
- 支持子菜单（下拉选项）
- 支持"更多"菜单（折叠不常用工具）
- 使用绝对定位避免被父容器裁剪

**布局选择模式**：
- 使用固定定位（fixed）的蒙层覆盖页面
- 通过 z-index 控制层级关系
- 状态管理确保模式切换流畅

## 6. 多语言支持

### 6.1 翻译文件结构

所有翻译定义在 `src/lib/i18n.ts` 中，包含：
- Header 相关文案
- 侧边栏标签
- 图层工具栏工具名称
- 通用操作（复制、删除、锁定等）
- 内容面板文案

### 6.2 使用方式

```typescript
import { useLanguage } from '@/contexts/language-context';

function MyComponent() {
  const { t, language, setLanguage } = useLanguage();
  
  return (
    <div>
      <button onClick={() => setLanguage(language === 'zh' ? 'en' : 'zh')}>
        {t.language}
      </button>
    </div>
  );
}
```

### 6.3 图标统一规范

相同功能的图标已统一：
- 删除：Trash2
- 复制：Copy
- 对齐：AlignCenter（根据上下文可用 AlignLeft/AlignRight）
- 对称和旋转：RotateCw
- 特效/颜色：Palette
- 编辑元素：Layers
- AI相关：Sparkles
- 增强：Wand2
- 移除背景：UserMinus
- 裁剪：Crop
- 调整：Sliders
- 下载：Download

```typescript
type LayerType = 'text' | 'image' | 'layout' | 'shape' | 'background';

interface BaseLayer {
  id: string;
  name: string;
  type: LayerType;
  visible: boolean;
  locked: boolean;
  zIndex: number;
  x: number;      // 百分比
  y: number;      // 百分比
  width: number;  // 百分比
  height: number; // 百分比
}

interface TextLayer extends BaseLayer {
  type: 'text';
  text: string;
  fontSize?: string;
  fontWeight?: string;
  color?: string;
  // ... 其他文字样式
}

interface ImageLayer extends BaseLayer {
  type: 'image';
  imageUrl: string;
  name?: string;  // 图片名称（贴纸会使用此字段）
}

interface ShapeLayer extends BaseLayer {
  type: 'shape';
  icon: string;   // 形状图标标识（star, heart, circle, square, triangle, hexagon）
  color?: string; // 形状颜色
}

// ... 其他图层类型
```
