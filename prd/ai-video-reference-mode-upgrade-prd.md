# AI Video 输入模式升级 PRD

> 文档版本：V1.6
> 更新日期：2026-08-13
> 适用页面：`/ai-video`

## 1. 需求背景

当前“参考图”仅支持图片，并使用 `image_to_video`；“首尾帧”只有前端形态，实际也复用 `image_to_video`。本次将“参考图”升级为支持图片、视频、音频的“全能参考”，并接入真实首尾帧接口。原有文生视频模型及自动判断逻辑保持不变，不新增文生视频入口。

## 2. 核心规则

页面只展示“全能参考”和“首尾帧”两个模式，具体分流如下：

| 页面状态 | 生成条件与处理 | `aigc_category` |
| --- | --- | --- |
| 全能参考，无参考素材 | Prompt 满足原有要求即可生成，继续使用原有文生视频模型 | `text_to_video` |
| 全能参考，有参考素材 | 存在任意合法图片、视频或音频；素材保留真实媒体类型 | `reference_image_to_video` |
| 首尾帧，仅有首帧 | 首帧有效即可生成 | `image_to_video` |
| 首尾帧，首帧和尾帧齐全 | 两张图片分别作为首帧、尾帧提交 | `first_last_frame_to_video` |
| 首尾帧，无首帧或仅有尾帧 | 禁止生成 | 不发起请求 |

全能参考即使只上传一张图片，也必须使用 `reference_image_to_video`。删除尾帧后恢复为 `image_to_video`；删除首帧时不得将尾帧自动作为首帧。前端与服务端使用同一分流规则，服务端根据模式和实际素材再次确认 category，不得静默降级。

## 3. 页面调整

### 3.1 模式与上传区

- 模式入口顺序为“全能参考 → 首尾帧”，不展示独立的文生视频按钮。
- 全能参考使用统一素材区，按模型接口返回能力展示图片、视频、音频入口；上传后分别展示缩略图、视频封面或音频名称，并支持删除和重新上传。
- 首尾帧使用独立的“首帧（必填）”和“尾帧（选填）”上传位，支持预览、删除和替换。
- 上传素材在当前创作会话内统一保留；切换模型或模式时优先复用兼容素材，无法兼容的素材暂时隐藏且不参与当前任务，具体继承规则见 3.3。

### 3.2 模型、参数与生成按钮

- 切换模型后，同步更新支持的模式、上传入口、上传限制及画幅、时长、清晰度等参数；不支持的模式不展示。
- 全能参考无可用素材时按文生视频条件生成；有可用素材时需当前上传区中的素材全部上传成功并符合模型限制。首尾帧上传有效首帧后即可生成。
- 仅有尾帧、当前上传区存在上传中或校验失败的新素材时，生成按钮禁用并在附近展示原因；因切换而暂存隐藏的历史素材不影响按钮状态。
- Prompt、模板入口及现有参数控件的基础布局保持不变。

### 3.3 模型、模式切换与素材继承

素材以当前创作会话为范围统一保存，并保留真实媒体类型、上传顺序及首尾帧角色。切换时遵循“兼容则复用，不兼容则隐藏，同一素材位有新上传则替换”的原则：

| 切换场景 | 素材处理 |
| --- | --- |
| 切换模型后，原素材符合新模型及当前模式限制 | 继续在原素材位展示并直接复用，无需重新上传 |
| 切换模型后，原素材不符合类型、大小、格式、尺寸、时长或组合限制 | 对应素材从当前上传区隐藏并暂存，不计入当前数量、不参与生成请求，也不阻塞生成 |
| 切换模型后，原素材数量超过新模型限制 | 按原上传顺序保留允许数量内的素材，超出部分暂存隐藏 |
| 新模型不支持当前模式，页面自动切换模式 | 先切换到新模型支持的第一个模式，再按目标模式和新模型限制复用素材，不清空全部素材 |
| 未上传新素材，再切换到兼容的模型或模式 | 暂存素材恢复到原素材位或原上传顺序并再次展示 |
| 原素材隐藏期间，对应素材位上传新素材 | 新素材替换原暂存素材；首尾帧按首帧位、尾帧位对应，全能参考按原上传顺序优先填补隐藏位置，后续不再恢复旧素材 |
| 从全能参考切换到首尾帧 | 按原上传顺序复用前两张兼容图片：第一张作为首帧，第二张作为尾帧；其他图片、视频和音频暂存隐藏 |
| 从首尾帧切换到全能参考 | 首帧和尾帧作为图片参考素材复用，顺序保持为首帧在前、尾帧在后；与全能参考中已暂存的素材按原顺序合并并去重 |
| 用户主动删除素材 | 从当前创作会话中彻底删除，各模型和模式均不再恢复 |

因切换而隐藏的素材不显示在上传框中，但仍保留原素材位和上传顺序。全能参考无可用素材时按文生视频处理；首尾帧无可用首帧时禁止生成。用户在当前模型下新上传但校验失败的素材仍需显示具体错误，并在删除或替换前阻塞生成。

## 4. 上传限制

素材格式、大小、数量、时长、尺寸和组合方式全部以模型接口返回结果为准。具体参数、校验规则及错误文案见 [AI Video 上传参数限制规格](./ai-video-upload-limits-spec.md)。已知限制必须提示具体原因；只有无法归因于参数限制的上传异常才使用简短兜底文案。

## 5. 验收标准

- 页面仅展示“全能参考”和“首尾帧”，切换模型或模式时优先复用兼容素材。
- 全能参考无素材时调用 `text_to_video`，有任意合法参考素材时调用 `reference_image_to_video`。
- 首尾帧仅有首帧时调用 `image_to_video`，首尾帧齐全时调用 `first_last_frame_to_video`，无首帧时不发起请求。
- 图片、视频、音频入口及上传限制与当前模型接口返回结果一致，素材保留真实媒体类型。
- 切换模式保留 Prompt 和通用参数；切换模型同步更新模式、上传限制和生成参数。
- 不兼容的继承素材从上传框隐藏且不参与生成；未被替换时，切回兼容模型或模式后自动恢复。
- 同一素材位上传新素材后只保留新素材；用户主动删除后不得在任何模型或模式中恢复旧素材。
- 当前模型下新上传的素材不符合限制时禁止生成，并展示实际值与模型允许值；因切换而隐藏的历史素材不阻塞生成，非限制类上传异常展示对应文件的失败提示。
