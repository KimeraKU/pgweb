# Prompt Template CMS PRD

> 版本：V1.0  
> 日期：2026-05-20  
> 页面：`/prompt-cms`  
> 目标：让运营/产品可配置 AI 功能的 Prompt 模版、变量、变量选项和前端表单展示

---

## 1. 为什么做

AI 功能的 Prompt 会频繁按业务、模型、地区和运营策略调整。如果每次都依赖研发改代码，迭代成本高，且无法快速验证不同 Prompt 和参数组合。

本 CMS 目标是把 Prompt 模版配置后台化：

- 按功能分类管理 Prompt。
- 在 Prompt 任意位置插入变量。
- 配置变量的前端展示名称、类型、选项、默认值和必填规则。
- 支持变量按业务维度分组，例如 `Basic profile`、`Face`、`Body`。

## 3. 功能范围

### 3.1 Prompt 分类管理

用于管理一级业务分类。

字段：

| 字段 | 说明 |
| --- | --- |
| 分类名称 | 例如 `AI Avatar` |
| 分类简述 | 该分类用途说明 |
| 模版数 | 当前分类下 Prompt 模版数量 |
| 更新时间 | 最近编辑时间 |

操作：

| 操作 | 说明 |
| --- | --- |
| 新增分类 | 弹窗创建分类 |
| 编辑分类 | 弹窗编辑名称和简述 |
| 删除分类 | 删除分类，同时删除该分类下模版 |
| 进入 | 进入该分类下的 Prompt 模版管理列表 |

### 3.2 Prompt 模版管理

用于管理全部或某个分类下的 Prompt 模版。

筛选项：

| 筛选项 | 说明 |
| --- | --- |
| 模版分类 | 下拉切换分类，支持 `All` 查看全部分类下的模版 |
| 关键词 | 支持按模版名称 / 模版 id 搜索 |
| 状态 | 全部状态 / 上架 / 草稿 / 下架 |

列表字段：

| 字段 | 说明 |
| --- | --- |
| ID | 模版内部 id |
| 模版分类 | 模版所属功能分类 |
| 模版名称 | 后台识别名称 |
| 模版 id | 业务唯一标识 |
| 变量数 | 当前模版变量数量 |
| 状态 | 上架 / 草稿 / 下架 |
| 更新时间 | 最近编辑时间 |

操作：

| 操作 | 说明 |
| --- | --- |
| 新增模版 | 创建新模版；若列表筛选为指定分类，则默认使用该分类；若筛选为 `All`，则使用当前上下文分类作为默认分类，编辑页仍可修改 |
| 编辑 | 进入 Prompt 模版编辑页 |
| 复制 | 复制当前模版为草稿 |
| 删除 | 删除当前模版 |
| 修改状态 | 在列表中直接切换状态 |

### 3.3 Prompt 模版编辑

编辑页分为左右两区：

| 区域 | 说明 |
| --- | --- |
| 左侧 | Prompt 输入框和渲染结果 |
| 右侧 | 变量列表、变量分类管理、变量新增/编辑 |

基础字段：

| 字段 | 说明 |
| --- | --- |
| 分类 | 当前模版所属分类 |
| 模版名称 | 后台名称 |
| 模版 id | 业务唯一标识 |
| 状态 | 上架 / 草稿 / 下架 |

Prompt 输入框：

- 支持手动输入 Prompt。
- 支持变量 token，例如 `{{gender}}`。
- 点击变量 token 按钮可插入到光标位置。
- 拖拽变量 token 到输入框可插入。
- 保存变量名变更时，Prompt 中对应 token 自动更新。

渲染结果：

- 使用变量默认值渲染 Prompt。
- 没有默认值时展示变量占位。

## 4. 变量设计

### 4.1 变量分类

变量分类用于控制前端表单维度和后台变量列表分组。变量分类是可选字段，变量可以不归属任何分类。

示例：

| 分类 |
| --- |
| Basic profile |
| Face |
| Body |

操作：

| 操作 | 说明 |
| --- | --- |
| 管理分类 | 打开变量分类弹窗 |
| 新增分类 | 新增当前模版下的变量分类 |
| 编辑分类 | 修改分类名称，同时更新该分类下变量 |
| 删除分类 | 删除后，该分类下变量变为无分类 |

变量分类属于具体 Prompt 模版，不是全局分类。
系统不强制创建默认变量分类；`General` 只有在运营手动创建或历史数据中存在时才作为普通分类出现。

### 4.2 变量字段

| 字段 | 说明 |
| --- | --- |
| 变量名 | Prompt token 名称，例如 `gender`，插入为 `{{gender}}` |
| 变量分类 | 可选，所属变量分类，例如 `Basic profile`；为空时表示无分类 |
| 前端显示名称（中文） | 前端表单中文名称 |
| 前端显示名称（English） | 前端表单英文名称 |
| 类型 | 填空 / 选项 / 选项+填空 |
| 默认值 | 渲染 Prompt 时默认使用的值 |
| 占位提示 | 前端输入框 placeholder |
| 选项 | 每行一个选项，仅类型为选项或选项+填空时展示 |
| 必填 | 前端是否必填 |

### 4.3 变量类型

| 类型 | 前端表现 |
| --- | --- |
| 填空 | 用户手动输入 |
| 选项 | 用户只能从预设项选择 |
| 选项+填空 | 用户可选择预设项，也可自定义输入 |

## 6. 交互规则

- 新增/编辑分类使用弹窗。
- 新增/编辑变量使用弹窗。
- 变量分类管理使用弹窗。
- 变量列表支持无分类变量；有分类的变量按变量分类分组展示。
- 变量分类不是必填字段，新增/编辑变量时允许选择无分类。
- 系统不内置强制默认变量分类。
- 删除变量分类后，该分类下变量自动变为无分类。
- 删除变量时，同时删除 Prompt 中对应 token。
- 修改变量名时，同时替换 Prompt 中旧 token。
- 新建模版默认带一个无分类的 `subject` 填空变量。
- 保存模版后返回该模版所属分类的 Prompt 模版列表。

## 7. 数据结构建议

### 7.1 Prompt 分类

```json
{
  "id": "ai_avatar",
  "name": "AI Avatar",
  "description": "AI Avatar、写真、人物风格化相关 Prompt",
  "updated_at": "2026-05-20 12:00:00"
}
```

### 7.2 Prompt 模版

```json
{
  "id": 3,
  "category_id": "ai_avatar",
  "name": "AI Avatar 模特参数 Prompt",
  "template_id": "ai_avatar_model_prompt",
  "status": "active",
  "prompt": "Create a high-fashion AI avatar portrait...",
  "variable_groups": ["Basic profile", "Face", "Body"],
  "variables": []
}
```

### 7.3 变量

```json
{
  "id": "var-avatar-gender",
  "name": "gender",
  "group": "Basic profile",
  "display_name": {
    "zh": "性别",
    "en": "Gender"
  },
  "type": "select_text",
  "placeholder": "选择或输入性别",
  "default_value": "女",
  "options": ["女", "男"],
  "required": true
}
```

## 8. 验收标准

- 可以新增、编辑、删除 Prompt 分类。
- 可以进入任一分类查看对应 Prompt 模版列表。
- Prompt 模版页可以按 `All` / 指定分类、关键词、状态筛选。
- Prompt 模版列表展示每条模版所属分类。
- 可以新增、编辑、复制、删除 Prompt 模版。
- 可以在编辑页修改 Prompt 内容和基础信息。
- 可以新增、编辑、删除变量分类。
- 变量允许无分类；有分类变量按变量分类分组展示。
- 可以新增、编辑、删除变量。
- 变量支持填空、选项、选项+填空三种类型。
- 变量支持中英文前端显示名称。
- 点击变量 token 可以插入 Prompt 输入框。
- 拖拽变量 token 可以插入 Prompt 输入框。
- 修改变量名后，Prompt 中旧 token 自动替换。
- 删除变量后，Prompt 中对应 token 自动删除。
- 保存模版后返回 Prompt 模版列表。
