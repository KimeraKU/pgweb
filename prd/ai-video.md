## 1. 入口与页面结构

### 1.1 入口

- 页面路由：`/ai-video`
- 顶部提供返回编辑器入口（返回 `/editor`）。

### 1.2 页面布局（桌面端）

- 左栏：模板分类与模板库（用于快速套用思路）。
- 中间主区：任务流（按时间顺序展示任务、状态与视频结果）。
- 右栏：资产列表（任务摘要、状态、下载、删除）。
- 底部浮层输入区：参考图上传、模板缩略图位、prompt 输入、参数区、生成按钮（支持收起/展开与高度扩展）。

### 1.3 移动端行为

- 左右栏以抽屉形式打开/关闭。
- 中间主区保留为核心展示区，底部输入区固定可用。

## 2. 功能需求详述

### 2.1 任务创建

- 必填：`prompt`（最多 2500 字）。
- 可选：参考图（最多 7 张）。
- 参数项（根据接口定）：
  - 模型（以 `kling-video-o1` 为例）。
  - 输入模式（`参考图` / `首尾帧`，当前以 `参考图` 模式为主）。
  - 画幅（`16:9` / `9:16` / `1:1`）。
  - 时长（`5s` / `10s`）。
  - 清晰度模式（`720p` / `1080p`）。
- 点击「生成」后新增一条任务，状态进入 `pending`，创建成功后进入 `processing`。

### 2.2 任务状态与展示

- `processing` / `pending`：显示统一比例（16:9）生成中占位区。
- `succeeded`：显示视频播放器（带 controls）。
- `failed`：显示错误信息与「重试」按钮。
- `submitted`：显示“任务已提交上游”说明与 task_id（用于回调型结果）。

### 2.3 任务操作

- 编辑任务：将该任务 prompt 与参数回填到底部输入区。
- 再次生成：基于该任务参数直接再发起一条新任务。
- 删除任务：移除任务并停止其轮询。
- 失败重试：在原任务上重试，不新增记录。

### 2.4 输入区交互

#### 2.4.1 区域结构（从上到下）

- 顶部工具行：模板位、参考图上传按钮、已选模板缩略图、参考图缩略图列表。
- 中部输入行：prompt 文本输入区域（支持展开高度）。
- 底部参数行：模型、输入模式、画幅、时长、清晰度、重置、字数、生成按钮。

#### 2.4.2 收起 / 展开

- 输入区支持整体收起为紧凑条形态：
  - 左侧：展开按钮。
  - 中间：当前 prompt 摘要（空时显示占位文案）。
  - 右侧：快速生成按钮。
- 展开后恢复完整输入区，保留用户已填写内容（prompt、参考图、参数、模板选择）。

#### 2.4.3 prompt 输入规则

- 字数上限：2500，实时显示计数 `当前字数/2500`。
- 输入框默认紧凑高度，可通过右上角 icon 切换为大高度（便于编辑长 prompt）。
- 输入框仅保留光标反馈，不额外显示外层选中框。

#### 2.4.4 模板与参考图交互

- 模板位默认显示“模版”占位按钮。
- 选中左侧模板后：
  - 模板预设 prompt 自动写入输入框；
  - 模板位展示为缩略图（样式与参考图缩略图一致）；
  - 可通过缩略图右上角移除按钮清空模板选择。
- 参考图：
  - 最多 7 张；
  - 缩略图样式与模板缩略图一致；
  - 移除按钮默认隐藏，仅在 hover/focus 时显示。

#### 2.4.5 参数与生成行为

- 参数区包含：模型、输入模式、画幅、时长、清晰度模式、重置按钮。
- 点击「生成」时：
  - 当 `prompt` 为空，按钮禁用；
  - 当请求进行中，按钮显示 loading 并禁用重复提交。
- 点击「重置」时清空：prompt、模板选择、参考图、参数（恢复默认值）。

### 2.5 模板联动

- 左侧模板库点击后，将模板预设 prompt 填入输入框。
- 填充后自动展开输入条并展开 prompt 区，便于直接编辑再生成。
- 输入区“模板”位显示当前选中模板缩略图；未选中时显示占位按钮。

### 2.6 资产列表功能（补充）

- 资产列表支持关键词搜索（按 prompt / 任务 id 过滤）。
- 支持日历筛选入口（用于按时间维度筛选资产，当前可先按 UI 入口保留）。
- 每条资产支持：选中定位到中间任务、复制链接、下载、删除。

### 2.7 拖拽交互（补充）

- 资产缩略图支持拖拽（dragstart）导出链接。
- 用户可将缩略图拖到桌面或可接收 URL 的应用中。
- 拖拽时需保证：
  - 不影响常规点击选中任务。
  - 拖拽数据包含可用链接（优先视频链接，其次缩略图链接）。

### 2.8 接口设置（本地持久化）

- 用户可在设置弹窗填写并保存：
  - `callback_url`
  - `user_id`
  - `app_id`
  - `tenant_id`
  - `model_version_id`
  - `task_query_url`
  - `api_key`
- 保存到 localStorage：`ai-video-aigc-config-v1`。

## 3. 接口与数据约束

### 3.1 创建任务接口

- 前端请求：`POST /api/video/kling-o1`
- 服务端转发上游创建接口。
- 参考图模式下：
  - 有图：`category = image_to_image`
  - 无图：`category = text_to_video`

### 3.2 轮询接口

- 前端轮询：`GET /api/video/kling-o1?task_id=...`
- 轮询周期：约 3 秒。
- 长时间无可播放地址时转 `submitted`，避免无限轮询。

### 3.3 参考图上传接口

- 上传接口：`POST /api/upload/crevibe-batch-images`
- 成功后返回 URL 列表，参与创建任务请求。

### 3.4 本地数据

- 历史任务：`ai-video-history-v1`
- AIGC 设置：`ai-video-aigc-config-v1`

## 4. UI 与交互规范

- 视觉基调：浅色（slate + teal）。
- 中间任务区采用流式展示，避免重卡片堆叠。
- 视频区各状态（生成中/成功/失败）保持一致展示比例，减少跳动。
- 输入区、侧栏、资产区间距收敛，避免无意义大留白。
- 关键交互元素具备 clear hover / active / disabled 态。
