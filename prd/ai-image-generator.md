## 1. 产品概述

### 1.1 产品定位

AI Image Generator 是聚合编辑器（Aggregation Editor）左侧边栏「应用」Tab 下的首个应用，为用户提供基于文本提示词（及可选参考图）的 AI 图片生成能力，并在同一面板内展示生成结果、支持重新生成、反馈与下载。

### 1.2 核心价值

- **一站式生图**：在编辑器内完成提示词输入、模型/参数选择、生成与结果查看，无需跳转。
- **多模型与多参数**：支持多种生成模型与尺寸/比例，满足不同场景。
- **参考图与预设**：支持添加参考图、预设标签与「更多」预设弹窗，提升出图可控性与效率。
- **结果可操作**：每条生成结果支持重新生成、点赞、点踩、下载，便于筛选与沉淀。

### 1.3 目标用户

- 在聚合编辑器中需要快速出图的创作者
- 需要尝试不同模型/比例并对比效果的用户
- 依赖参考图或预设提示词降低门槛的轻度用户

## 2. 入口与布局

### 2.1 入口

- **位置**：左侧边栏 → **Apps** Tab → 应用网格**最上方**三个应用之一（首期可点击：AI Image Generator、AI Video Generator、AI Filter）；其余应用为 2 期，置灰并带「Phase 2」徽标，不可点击。
- **标识**：名称为「AI Image Generator」（多语言见后），图标为 `image_fast.svg`，背景渐变为 `from-purple-400 to-pink-300`。
- **行为**：点击后在该侧栏下方以**动态 App Tab** 形式打开「AI Image Generator」内容区，与「batch」等常驻 Tab 并列；Tab 可关闭（hover 显示关闭按钮）。
- **左侧栏 Tab 形态**：由 Apps 打开的动态 Tab 在左侧栏仅显示**圆形 logo**（图标置于圆形容器内，无文字），与常驻 Tab（图标 + 文字）形成差异；悬停时通过 `title` 展示应用名称。

### 2.2 内容区整体布局

- **顶部**：固定标题栏，展示当前应用名称（多语言）。
- **上方区域**：可滚动列表，用于展示**生成图**（无单独「Generated」标题）。
- **下方固定区域**：主输入框、模型/参数选择、生成按钮，从上到下依次排列。

## 3. 功能需求详述

### 3.1 主输入框

- **结构**：一个带边框、可聚焦的容器，内含：
  - **顶部区域（同一容器）**：参考图添加区（左上，见 3.2）+ **右上角**高度拖拽手柄（等腰直角三角形、直角圆角），手柄与图片添加区在同一 flex 容器内，便于与下方文案区区分。
  - **中部**：多行文本输入（textarea），占位符为「输入图片生成的提示词，例如: …」，**字数上限 2000**（maxLength=2000）。
  - **底栏单行**：左侧为魔杖（AI 优化提示词）+ 预设标签（前 2 个）+「更多」按钮；右侧为字数统计（当前/2000）、竖线分隔、删除（清空）按钮；左右边距与 `left-2`/`right-2` 一致，单行不换行、不重叠。
- **高度**：默认约 160px，拖拽手柄可调范围 120px～320px；手柄在**右上角**时，向下拖拽为缩小高度，向上为增大。
- **焦点**：获得焦点时显示 ring（如 teal）。

### 3.2 参考图

- **入口**：主输入框左上角「添加」按钮（带 Plus 图标）。
- **数量**：最多 14 张；达上限后添加按钮置灰不可点。
- **展示**：小缩略图网格排列，每张带移除按钮（右上角减号）。
- **说明**：当前为占位能力（无实际上传/预览逻辑），PRD 仅定义布局与数量限制。

### 3.3 提示词与预设

- **输入**：中部 textarea，支持多行，不可 resize（由顶部高度手柄控制输入框整体高度）；**字数上限 2000**，底栏右侧展示「当前字数 / 2000」。
- **魔杖**：底栏左侧「AI 优化提示词」按钮（Wand2 图标，小号），点击后预期对当前提示词做 AI 优化（具体接口与行为待接后端）。
- **预设标签**：底栏固定展示前 2 个（如「Poster」「Flyer」），点击可追加到当前提示词末尾；过长时截断（max-width + truncate）。
- **更多**：底栏「更多」按钮，点击后打开「预设」弹窗，展示更多预设选项（如 Create Poster、Spaceship、Halloween Theme Poster 等），选择后可将该预设填入或追加到提示词（具体逻辑与当前实现保持一致）。
- **字数与删除**：底栏右侧为「当前字数 / 2000」（小号、浅灰）、竖线、删除图标（Trash2）；点击删除可清空整段提示词；与左侧魔杖/预设同排单行展示，不重叠。

### 3.4 模型与参数

- **模型**：
  - 通过下拉选择，当前选项包括但不限于：Nano Banana Pro、SeeDream 4.5、midjourney、SeeDream 4.0、Nano Banana、wan2.6 等。
  - 下拉在按钮**上方**展开，选项展示模型图标 + 名称 + 选中态（单选勾）。
- **参数**：
  - 合并为单一下拉，展示「尺寸 · 比例」（如 1K · 1:1）。
  - 尺寸选项：1K / 2K / 4K。
  - 比例选项：1:1、3:2、2:3、3:4、4:3、4:5、5:4、9:16、16:9、21:9。
  - 下拉同样在按钮上方展开。

### 3.5 生成与生成图列表

- **生成按钮**：位于固定区域最底部，主样式与「Upload」等保持一致（如 teal、Zap 图标、文案「生成」）。点击后向列表追加一条生成记录（占位：无真实接口时仅写入 id、createdAt、modelName，无 url 时显示「生成中…」）。
- **列表**：
  - 无单独「Generated」标题；列表直接为可滚动内容。
  - 每条记录为一张卡片，包含：
    - **图片区域**：正方形比例，最大高度约 192px；无图时显示「生成中…」。
    - **左上角**：模型名称标签（半透明深底、白字、小号字体，过长截断）。
    - **下方操作栏**：
      - **左侧**：「重新生成」按钮（RotateCcw 图标 + 文案），点击后移除当前条并以当前模型再生成一条新记录并追加到列表末尾。
      - **右侧**：三个图标按钮——点赞（ThumbsUp）、点踩（ThumbsDown）、下载（Download）；当前为 UI 与占位交互，无后端反馈/下载逻辑。
  - 列表按时间从旧到新排列，新项追加后自动滚动到底部。

### 3.6 其他交互

- **预设弹窗**：由「更多」触发，标题为「预设」，带关闭按钮；位置在「更多」按钮上方（非屏幕居中），避免遮挡输入区。
- **点击外部**：模型下拉、参数下拉在点击外部时关闭；预设弹窗关闭方式与现有实现一致。
- **高度手柄**：位于图片添加区容器右上角，等腰直角三角形（直角圆角），视觉尺寸约 24×24px（w-6 h-6），SVG 渲染 18×18；拖拽时光标为 `ns-resize`。

## 4. 界面与交互

### 4.1 尺寸与样式约定

- 侧栏内容区宽度：约 320px（w-80）。
- 输入框、下拉、按钮等与现有编辑器风格一致（圆角、边框、teal 强调色）。
- 生成图卡片：圆角、浅底、边框，操作栏与图片区有分隔线。

### 4.2 无障碍与语义

- 右上角高度手柄使用 `role="slider"` 与 `aria-label="调整输入框高度"`。
- 点赞/点踩/下载按钮提供 `title` 与 `aria-label`；删除按钮使用 `t.delete` 作为 `title` 与 `aria-label`。
- 动态 App Tab 在左侧栏通过 `title={label}` 提供悬停名称，便于识别。

## 6. 后续扩展说明

以下为当前未实现或仅占位的部分，PRD 仅作范围说明，不做实现承诺：

- **参考图**：实际上传、预览、与生成接口的关联。
- **魔杖**：AI 优化提示词的后端接口与前端结果回填。
- **生成**：真实生图 API 调用、轮询/长连接、结果 url 回写与错误态。
- **点赞/点踩**：反馈上报与可选展示（如点赞数）。
- **下载**：单张生成图下载（格式、分辨率、水印策略等）。
- **模型/参数**：与后端能力联动（动态模型列表、按模型限制比例等）。

以上扩展需与后端、商业化策略及聚合编辑器整体规划对齐后再细化需求与优先级。
